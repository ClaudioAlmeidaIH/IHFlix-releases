# IH Flix — versões

Este repositório guarda apenas os APKs prontos do IH Flix, o app de Android TV das cabines do
Instituto Homem. As TV boxes consultam a versão mais recente aqui e se atualizam sozinhas.

- **Baixar a versão atual:** [ihflix.apk](https://github.com/ClaudioAlmeidaIH/IHFlix-releases/releases/latest/download/ihflix.apk)
- **Todas as versões:** aba [Releases](https://github.com/ClaudioAlmeidaIH/IHFlix-releases/releases)

O código-fonte fica em outro repositório, privado.
